# Public inputs and provenance

Only public-source analysis code and data are included in this project. Source discovery, capture dates, hashes, unresolved protocol/version issues and exact coverage are documented in the linked audits in README.md. Original acquisition manifests are preserved.

Main sources:

- Artificial Analysis public scores, captured in the [frontier-ai-economic-validity reproducibility bundle](https://github.com/louisyzhu/frontier-ai-economic-validity). The original bundle contains the archived page used to verify all selected scores and release dates.
- [LiveBench](https://github.com/LiveBench/livebench.github.io), including versioned question/result metadata and aggregate exports.
- [Epoch AI benchmarks](https://epoch.ai/benchmarks), including exact configuration records and separate processed ECI constituent tables. The downloaded ZIP README specifies CC BY 4.0; retain attribution and original external-source citations.
- Hugging Face sources, source repository URLs and pinned revisions: `download_public_datasets.sh`, `public-data/acquisition-manifest.json`, `public-data/host-download-manifest.json` (local ignored file), and per-dataset metadata.

Public accessibility is not a blanket redistribution license. Raw third-party downloads and embedded repositories are kept local and ignored by Git. Their original licenses/terms continue to apply; this project does not relicense them. Compact derived reports and matrices retain source attribution through their audit metadata. A comprehensive redistribution/legal review and a code-license choice have not been performed.

Saved scientific metadata and code hashes are historical records. Migration copies the shared numerical helper and splits its public/internal tests, while preserving original analysis scripts and saved scientific results. Local machine paths in ignored historical acquisition notes/logs refer to the former working directory, not runtime dependencies.
